Implementation Reference

NAZZTEC — Webflow Build Spec

Everything needed to rebuild the homepage concept natively in Webflow: Client-First class naming for every element, CMS Collection schemas, native interactions to replace the concept's JS, and a build order. Written against the nazztec-homepage concept artifact — treat that as the visual source of truth and this as the construction spec.

Overview

This isn't a Webflow export — no Webflow API is connected in this environment, so nothing here has been built inside Webflow itself. It's a spec written so a builder (you, or a Webflow developer) can construct it directly without re-deriving structure or naming decisions.

Client-First primer — classes are named by role, not appearance (section_hero, not blue-box), reused across instances via Webflow's Style panel (not Combo classes for one-offs), and scoped so global patterns (padding-global, container-large) wrap every section identically.

Global Structure

Interactions (IX2)

Everything the concept did in vanilla JS maps to native Webflow interactions — no custom code embed required.

Concept behaviorWebflow equivalent
Section fade/slide-in on scrollWhile scrolling in view trigger on each [data-reveal] equivalent (add class is-reveal), Move 14px + Opacity 0→100%, per-section, once
Sticky nav shadow after scrollScroll into view / Page scroll trigger on Navbar → add is-scrolled class past 8px (Webflow: "While page is scrolling," 0–20px range)
Mobile hamburger open/closeNative Navbar component open/close states — built-in, no IX2 needed
Index row hover (arrow shift, tint)Native Hover state on Combo class, no IX2 needed
Stat count-up (3 / 8 / 4)Rebuild as a short IX2 While scrolling in view + Lottie number count, or keep as a tiny embedded script — this one is reasonable to keep as code since Webflow has no native counter
Canvas node-network ambient backgroundRecreate as a looping Lottie/video background, or keep the concept's small canvas script as an embed — do not rebuild in pure Webflow interactions
Respect reduced motion: in Webflow, duplicate the reveal interaction set as None when prefers-reduced-motion — Webflow doesn't expose this natively, so gate it with a one-line custom code check that toggles a body class, same as the concept.

Build Order

  1. 01 Set up Variables (color, type, spacing) in Style panel
  2. 02 Set global type styles (H1–H3, body, mono) and the page-wrapper / padding-global / container-large base classes
  3. 03 Build Navbar Symbol and Footer Symbol first — they touch every page
  4. 04 Create the 3 CMS Collections and enter real content (start with Services — it's the load-bearing one)
  5. 05 Build the Homepage section by section, top to bottom, binding the Services index and Locations cards to their Collection Lists as you go
  6. 06 Build the Services Collection Page template, bind all fields
  7. 07 Build Staff Augmentation, About, Contact as static pages reusing the same section/component classes
  8. 08 Add IX2 interactions per the table above; add the reduced-motion body-class embed
  9. 09 Responsive QA at 1440 / 991 / 767 / 479px breakpoints
  10. 10 Publish to staging — e.g. nazztec-redesign.webflow.io — for client review
