# NAZZTEC Website Redesign — UAT v1

A homepage design concept and implementation spec for NAZZTEC's corporate website redesign, built for an internal UAT review before a full Webflow build.

NAZZTEC is a technology consulting company (cybersecurity, cloud, managed services, digital transformation, staff augmentation) operating out of India, Saudi Arabia, and the United States. This project repositions their web presence to read as an enterprise consultancy rather than a generic IT vendor.

## Live preview

[`index.html`](./index.html) — live at https://annu-rai.github.io/nazztec-website-uat/

## Contents

- **`index.html`** — the homepage concept: hero, global presence, an 8-domain capability index, staff augmentation, why-NAZZTEC, framework & regulatory expertise, digital transformation, engagement models, industries (placeholder), CTA, and footer.
- **`docs/project-brief.html`** — a one-page project brief covering scope, design rationale, and next steps.
- **`docs/webflow-spec.html`** — the implementation spec for rebuilding this in Webflow: Client-First class naming for every component, CMS collection schemas (Services, Locations, Insights), interaction mapping, and build order.

## Design system

- **Type** — Fraunces (display), Public Sans (body), IBM Plex Mono (data/reference codes)
- **Color** — brand blue `#17457F`, ink `#0E1B2B`, signal accent `#0FAFC4`, slate `#5C6B78`
- **Layout** — full-bleed photography-led hero (Slalom/PwC/Kyndryl-inspired), elevated icon-badge card grids for Services/Why/Engagement/Presence/Industries, and a sticky scroll-spy sub-navigation

## Status

Design concept stage — pending stakeholder sign-off before the Webflow build begins. The Industries section and several content areas (About, Careers, Insights) are explicitly marked as placeholders pending client input.
